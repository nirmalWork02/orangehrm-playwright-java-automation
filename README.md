# orangehrm-playwright-java-automation
UI Automation framework for OrangeHRM using Playwright, Java, TestNG, Maven and Page Object Model.
# OrangeHRM UI Automation Framework

## Project Overview
This project automates selected user interface workflows of the OrangeHRM demo application using Playwright with Java.

## Application Under Test
https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

## Technology Stack
- Java
- Playwright for Java
- TestNG
- Maven
- Page Object Model (POM)
- Git and GitHub

## Test Scenarios
1. Login with valid credentials
2. Login with invalid username
3. Login with invalid password
4. Login with empty username
5. Login with empty password

## Framework Features
- Page Object Model
- TestNG assertions and test execution
- Reusable browser setup
- Configuration management
- Failure screenshots and test reporting (as implemented)

## Prerequisites
- Java JDK
- Maven
- Eclipse IDE or another Java IDE

## How to Run
1. Clone this repository.
2. Open the project in your IDE.
3. Configure the required test settings.
4. Run the TestNG test suite or execute the tests using Maven.

## Project Status
Initial version: Login page automation.

## Disclaimer
This project is created for learning and portfolio demonstration using a public demo application.
